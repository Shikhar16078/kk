# **App Name**: DevCard

## Core Features:

- Intro Section: A brief introduction with a professional photo and a captivating headline to immediately grab attention.
- Work Experience Section: Display previous work experience, using dates and company information. Include a list of accomplishments at each job using bullet points.
- Education Section: Show educational background including degrees, certifications, and relevant coursework or projects.
- Projects Section: Showcase software projects with descriptions, tech stacks, and links to live demos or GitHub repositories.
- Contact Section: Include a contact form and links to professional social media accounts, such as LinkedIn and GitHub.
- Skills Section: Dynamically generate a list of skills with the use of a generative ai tool. The list should be grouped and categorized by front end, back end, AI, databases and general skills.

## Style Guidelines:

- Background color: Dark navy (#242937) for a modern, sophisticated feel.
- Primary color: Electric purple (#BE5BFF) for highlighting important elements and calls to action.
- Accent color: Light lavender (#D0A9FF) as a subtle secondary highlight.
- Body text: 'Inter' sans-serif font, offering a clean and modern aesthetic.
- Headline text: 'Space Grotesk' sans-serif font, with a computerized, techy, scientific feel
- Use modern, minimalist icons for skills and technology stacks, in electric purple (#BE5BFF).
- Grid-based layout with generous padding for a clean and organized presentation.
- Subtle animations (e.g., fade-ins, transitions) for section reveals on scroll.
